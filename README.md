# Azure Administrator (AZ-104) Lab Portfolio

Welcome to my Microsoft Azure hands-on lab portfolio.

This repository documents the labs, scripts, configurations, and troubleshooting exercises I complete while preparing for the **Microsoft Certified: Azure Administrator Associate (AZ-104)** exam.

My goal is to use this repository as more than a study log. It is a growing technical portfolio that demonstrates my ability to apply Azure administration concepts in practical scenarios.

---

## Purpose

This portfolio is designed to showcase my hands-on experience with Microsoft Azure.

Throughout this training, I am building and managing Azure resources, working through real administrative scenarios, troubleshooting problems, and reinforcing the concepts required of an Azure Administrator.

Each lab will document:

- **Objective** — what I was asked to configure or accomplish
- **Azure services used** — the resources and tools involved
- **Implementation** — the steps, scripts, or commands used
- **Troubleshooting** — issues encountered and how I resolved them
- **Verification** — how I confirmed the solution worked
- **Key takeaways** — what I learned from the lab
